# WordWizard

There's going to be 2 parts to this game. The daytime and nightime.

In daytime, players must prepare spells using word combinations but to do so they need letters so maybe add someway of getting letters (
    - Could be by growing them
    - Could be by foraging them

)
In nighttime They must fight enemies

The game will be in 2d top view.
The game should be played in multiplayer.
